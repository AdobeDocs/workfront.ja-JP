## Workfront 2017.3 9月のプレビューリリース {#workfront-2017-3-september-preview-releases}

Workfront 2017.3 9月プレビューリリースウェビナーは、2017年9月26日午前9時（MT）にWorkfront リリース対応チームによって発表されました。 このウェビナーでは、9月にプレビュー環境で利用可能になった新機能に重点を置いています。
