# 2027年第1四半期リリース期間中のその他の機能強化

このページでは、2027年第1四半期リリースのプレビュー環境に対する機能強化について説明します。 これらの機能強化は、前述のように本番環境で利用できるようになります。

2027年第1四半期リリースサイクルのこの時点で利用可能なすべての変更のリストについては、[2027年第1四半期リリースの概要](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md)を参照してください。

## 強化リストの合計レコード数を確認する

>[!NOTE]
>
>プレビュー：2026年10月29日（PT）
>プロダクション高速リリース：2026年11月12日（PT）
>すべての人のための制作：2027年1月21日

拡張ビューにアイテムの合計数が表示されるようになり、フィルターの適用、検索、またはビューの変更に伴ってカウントが自動的に更新されるようになりました。 アイテム数は、常にユーザーの権限に基づいて完全にフィルタリングされた結果を反映します。

詳しくは、[拡張リストの使用](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)を参照してください。

## 強化されたリストでのクイック検索の結果の可視性の向上

>[!NOTE]
>
>プレビュー：2026年10月29日（PT）
>プロダクション高速リリース：2026年11月12日（PT）
>すべての人のための制作：2027年1月21日

拡張リストでクイック検索を使用して項目を検索すると、検索に一致しないレコードがすべてリストから削除され、一致する項目のみが表示されます。

この機能強化の前は、検索結果に一致する項目がハイライト表示されているすべての項目が表示されていました。

詳しくは、[拡張リストの使用](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)を参照してください。

## 拡張リストの更新

>[!NOTE]
>
>プレビュー：2026年10月29日（PT）
>プロダクション高速リリース：2026年11月12日（PT）
>すべての人のための制作：2027年1月21日

拡張リストに対して、次の変更が行われました。

* 最初の列の上部にある矢印アイコンを使用して、拡張リスト内のすべてのグループを展開または折りたたむことができるようになりました。 以前は、グループ化の設定内のすべてのグループを展開または折りたたむことしかできませんでした。
* 新しいビューを作成する際に、使用可能なタイプが1つしかない場合に、ビュータイプを選択する必要がなくなりました。

詳しくは、[拡張リストの使用](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)を参照してください。

## 複数の画面を拡張リストに更新

>[!NOTE]
>
>プレビュー：2026年10月29日（PT）
>プロダクション高速リリース：2026年11月12日（PT）
>すべての人のための制作：2027年1月21日

次のWorkfront リストでは、拡張リスト形式が使用されるようになりました。

* 設定/インターフェイス/レイアウトテンプレート
* 設定/電子メール/通知/イベント通知およびグループの詳細ページ/イベント通知

更新には、リストの一部または全部に関する次の内容が含まれます。

* 色、フォーマット、フォントが更新され、リストの新しいルックアンドフィールが得られます。
* リストに新しいオブジェクトを作成するオプションが右上に移動され、青いボタンとして表示されます。
* ツールバーが削除されました。 これで、表内の1つ以上のオブジェクトを選択すると、アクションバーがリストの下部に青色で表示されるようになりました。
* 一部の列が再配置または削除されたか、新しい列が追加された可能性があります。
* 一部の確認と警告が削除または変更されました。
* 一部のリストの保存が自動的になり、「保存」ボタンが削除された可能性があります。
* 一部の強化されたリストでは、列の名前を変更したり並べ替えたりできます。
* 強化されたリストには、列の追加と配置を行うことができる列マネージャーが含まれています。 Workfrontでは、ネイティブフィールドまたはカスタムフィールドで列を選択できます。
* 表のセル内のアイコンは、複数のオプションを持つ「その他」メニューに置き換えられました。

>[!NOTE]
>
>一部の更新はすべてのリストで利用できるわけではありません。

詳しくは、[拡張リストの使用](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)を参照してください。

## カレンダーレポートの週ビューでの時間の表示と非表示の切り替え

>[!NOTE]
>
>プレビュー：2026年10月29日（PT）
>プロダクション高速リリース：2026年11月12日（PT）
>すべての人のための制作：2027年1月21日

カレンダーレポートの週表示で、その日の時間を表示または非表示にできるようになりました。 時間を非表示にすることで、週の表示をよりシンプルに、より合理的に表示したり、時間帯区分が必要な場合に表示したりできます。 カレンダーの右上隅にある切り替えスイッチを使用して、2つを切り替えます。

詳しくは、[&#x200B; カレンダーレポートとイベントの詳細の表示](/help/quicksilver/reports-and-dashboards/reports/calendars/view-calendar-reports-and-event-details.md)を参照してください。
