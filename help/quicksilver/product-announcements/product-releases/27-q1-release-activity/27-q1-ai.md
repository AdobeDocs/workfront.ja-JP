# 2027年第1四半期：AIの強化

このページでは、プレビュー環境への2027年第1四半期リリースで行われたAIの機能強化について説明します。 これらの機能強化は、前述のように本番環境で利用できるようになります。

2027年第1四半期リリースサイクルのこの時点で利用可能なすべての変更のリストについては、[2027年第1四半期リリースの概要](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md)を参照してください。

## Workfront MCP server toolsets

>[!NOTE]
>
>プレビュー：2026年10月21日（PT）
>プロダクション高速リリース：2026年11月12日（PT）
>すべての人のための制作：2027年1月21日

AI クライアントがアクセスできるWorkfront機能を制御しやすくするために、Workfront MCP サーバーにツールセットを追加しました。 MCP カタログを、完全な許可されたツールリストを公開するのではなく、クライアントが必要とする機能に制限できるようになりました。 使用可能なツールセットには、`core`、`comment-stream`、`planning`、`approvals`があります。

また、利用可能なツールにより、製品の使用権限がより明確に反映されるようになりました。 Workfront Planningのライセンスをお持ちのお客様はプランニングツール、Workfront Workflowのライセンスをお持ちのお客様はワークフローツール、両方のライセンスをお持ちのお客様は両方のセットをご覧いただけます。

詳しくは、[Adobe Workfront MCP サーバーの設定](/help/quicksilver/workfront-basics/workfront-mcp-server/configure-workfront-mcp-server.md)および[Adobe Workfront MCP サーバーの使用](/help/quicksilver/workfront-basics/workfront-mcp-server/use-workfront-mcp-server.md)を参照してください。
