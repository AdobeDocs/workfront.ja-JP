# 2027年第1四半期：管理者の機能強化

このページでは、2027年第1四半期リリースのプレビュー環境に対する管理者の機能強化について説明します。 これらの機能強化は、前述のように本番環境で利用できるようになります。

2027年第1四半期リリースサイクルのこの時点で利用可能なすべての変更のリストについては、[2027年第1四半期リリースの概要](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md)を参照してください。

## 添付されたカスタムフォームを削除するための権限

>[!NOTE]
>
>プレビュー：2026年10月29日（PT）
>プロダクション高速リリース：2026年11月12日（PT）
>すべての人のための制作：2027年1月21日

カスタムフォームを共有する際に、フォームへの管理アクセス権を持つユーザーに対して、フォームが添付されているオブジェクトからフォームを削除する権限を設定できるようになりました。

詳しくは、[カスタムフォームを共有](/help/quicksilver/administration-and-setup/customize-workfront/create-manage-custom-forms/share-access-to-a-custom-form.md)を参照してください。

## カスタムフィールドをお気に入りにマーク

>[!NOTE]
>
>プレビュー：2026年10月29日（PT）
>プロダクション高速リリース：2026年11月12日（PT）
>すべての人のための制作：2027年1月21日

フィールドリストまたはカスタムフォームデザイナーで、カスタムフィールドをお気に入りとしてマークできるようになりました。 特定のリストやレポート（プロジェクト、タスク、イシューリストなど）で作業し、フィルター、ビュー、グループ化を構築すると、お気に入りのフィールドが「候補」セクションの使用可能なフィールドのリストの上部に表示されます。

お気に入りとしてマークされたフィールドは、フォームデザイナーのフィールドライブラリの上部にも表示されます。

詳しくは、[ カスタムフォームの作成](/help/quicksilver/administration-and-setup/customize-workfront/create-manage-custom-forms/form-designer/design-a-form/design-a-form.md)を参照してください。

## 変更履歴がCanvas ダッシュボードオブジェクトを追跡するようになりました

>[!NOTE]
>
>プレビュー：2026年10月29日（PT）
>プロダクション高速リリース：2026年10月29日（PT）
>すべての人のための制作：2026年10月29日
>[!BADGE スケジュール外]{type=Neutral}

変更履歴では、Canvas ダッシュボードへの変更が記録されるようになりました。 ダッシュボードやレポートを作成、更新、削除したユーザー、作成日時、変更内容を確認できます。

Canvas ダッシュボードの変更のトラッキングを開始するには、設定/トラッキングの変更/設定で&#x200B;**ダッシュボード**、**レポート**&#x200B;および&#x200B;**レポート設定** オブジェクトを設定する必要があります。

詳しくは、[変更履歴の表示と管理](/help/quicksilver/administration-and-setup/add-users/create-and-manage-users/view-and-manage-change-history.md)を参照してください。
