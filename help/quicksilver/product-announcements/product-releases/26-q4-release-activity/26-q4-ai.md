# 2026年第4四半期：AIの強化

このページでは、プレビュー環境への2026年第4四半期リリースで行われたAIの機能強化について説明します。 これらの機能強化は、前述のように本番環境で利用できるようになります。

2026年第4四半期リリースサイクルのこの時点で利用可能なすべての変更のリストについては、[2026年第4四半期リリースの概要](/help/quicksilver/product-announcements/product-releases/26-q4-release-activity/26-q4-release-overview.md)を参照してください。

## CX CoworkerがWorkfrontで利用可能になりました

>[!NOTE]
>
>プレビュー：2026年9月3日から段階的に展開
>プロダクションの迅速リリース：2026年9月17日から段階的に展開
>すべての人に向けた制作：2026年10月15日から段階的に展開

CX Coworkerは、Workfront内で利用できるようになりました。 これで、Workfront全体で利用可能なパネルでCX Coworkerにアクセスできます。

CX Coworker Chatは、対話型のインターフェイスで作業を進めることができます。 目標を平易な言葉で説明し、Coworkerが作業を計画し、Workfrontと接続されたAdobeシステムをまたいで実行し、結果を検証し、完成した作業を承認のために返します。

Coworkerは、デフォルトで読み取り専用アクセスを使用する組織の既存のアクセス制御を尊重し、ユーザーが書き込みアクセスを取得する際にはシステム管理者が制御します。

Adobe Workfrontは、作業を完了するためのより強力な方法として、現在のAI アシスタントに取って代わりました。 Adobe Workfrontは、Adobeのエコシステムの一部であり、Workfrontに限定されません。

>[!IMPORTANT]
>
>CX Coworkerは現在、ヘルスケアや金融などの機密性の高いデータを扱う企業では利用できません。 AI アシスタントは、引き続きこれらの組織で利用可能です。

詳しくは、[CX Coworkerの概要](/help/quicksilver/workfront-basics/coworker-in-workfront/coworker-overview.md)を参照してください。

## Workfront MCP コネクタで使用できる新しいユーザー検索ツール

>[!NOTE]
>
>プロダクション：2026年8月13日

Workfront インスタンス内のユーザーをより迅速に見つけられるように、Workfront MCP コネクタに新しいツールを追加しました。

* ユーザーの検索

検索ユーザーツールにフルネームまたはフルネームを入力すると、一致するユーザーの上位に戻ります。 また、AI Collaboratorの「ボット」を通常のユーザーと一緒に結果に含めることもできます。

この変更の一環として、次のツールは非推奨（廃止予定）になりました。

* ドキュメントを検索
* プロジェクトの検索
* 名前でチームを検索
* 名前でユーザーを検索
* 現在のユーザーを取得
* スコープ別ドキュメントの取得

これらのツールを使用するワークフローがある場合は、名前によるIDの検索、Workfront データの検索、またはユーザーの検索ツールを代わりに使用するように更新します。

詳しくは、[Adobe Workfront MCP server tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md)を参照してください。

## Workfront MCP サーバーを使用して、Adobe Experience Managerにアセットを送信し、承認用のカスタムメッセージを追加します

>[!NOTE]
>
>プレビュー：2026年8月12日（PT）
>プロダクション：2026年8月12日

Workfront MCP コネクタの機能を拡張するために、次のツールを追加しました。

* AEMにリンクされたフォルダーにドキュメントを送信し、プロジェクトで使用可能なAEMにリンクされたフォルダーを一覧表示します。
* カスタムメッセージ、タイトル、承認者またはレビュー担当者、オプションの期日を含むドキュメントバージョンの承認をリクエストします。

詳しくは、[Adobe Workfront MCP server tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md)を参照してください。

## WorkfrontのタスクにAI タスクコラボレーターを割り当てる

>[!NOTE]
>
>プレビュー：2026年7月31日（PT）
>プロダクション高速リリース：2026年8月13日（PT）
>すべての人のための制作：2026年8月13日

WorkfrontでAI エージェントを使用して作業を実行できるようにするために、タスクコラボレーターを作成しました。 タスクコラボレーターは、ドキュメントやアセットのレビューに使用される既存のレビューアータイプのAI コラボレーターに加えて、Workfront タスクに直接割り当てることができるAI コラボレーターです。 タスクコラボレーターは、Copilot Studio、Claude、またはWriterで設定したエージェントに接続し、ユーザーを割り当てるのと同じようにタスクに割り当てます。

詳しくは、[AI コラボレーターの設定](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md)を参照してください。

## Workfront MCP コネクタで使用できる新しい承認ツール

>[!NOTE]
>
>プレビュー：2026年7月30日（PT）
>プロダクション高速リリース：2026年8月13日（PT）
>すべての人のための制作：2026年10月15日

Workfront MCP コネクタの機能を拡張するために、次の新しいツールを追加しました。

* 承認へのパスの追加
* 承認からパスを削除
* パスにステージを追加
* パスからステージを削除
* パス内のステージの並べ替え

また、並行して承認パスに対応するために、次のツールが拡張されました。

* 承認ワークフロー情報を取得
* 承認ワークフローの作成または更新
* テンプレートから承認を作成

詳しくは、[Adobe Workfront MCP server tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md)を参照してください。

## Workfront MCP コネクタで利用可能な新しい共有フィードバックツール

>[!NOTE]
>
>プレビュー：2026年9月3日（PT）
>プロダクション高速リリース：2026年9月17日（PT）
>すべての人のための制作：2026年10月15日

Workfront MCP サーバーの改善に役立てるために、Workfront MCP コネクタに新しいツールを追加しました。

* フィードバックを共有

フィードバックの共有を明示的に求める場合（「フィードバックの共有」や「バグの報告」など）、AI エージェンティックプラットフォームは、報告されたセンチメントと会話中に何が起こったのかを記録します。

詳しくは、[Adobe Workfront MCP server tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md)を参照してください。
