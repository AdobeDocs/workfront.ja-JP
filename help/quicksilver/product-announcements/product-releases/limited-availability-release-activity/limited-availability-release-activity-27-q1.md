# 2027年第1四半期のAdobe Workfrontの制限付き機能のリリースアクティビティ

この記事では、2027年第1四半期中にリリースされるWorkfront機能の限定提供について説明します。

<!--keep the sentence below for all future quarterly release pages-->

Adobe Workfront向けにリリースされたすべての制限付き機能の一覧については、[Adobe Workfront制限付き機能リリースアクティビティ：記事インデックス ](/help/quicksilver/product-announcements/product-releases/limited-availability-release-activity/limited-availability-release-activity-article-index.md)を参照してください。

## 制限付き機能のリリースノート

この節には、新機能のリリースノートが含まれています。

### すべてのグループを展開または折りたたむ機能

>[!NOTE]
>
>プロダクションリリース日：2026年10月27日（PT）

最初の列の上部にある矢印アイコンを使用して、拡張リスト内のすべてのグループを展開または折りたたむことができるようになりました。 これには、期間別レポートが含まれます。

以前は、グループ化の設定内のすべてのグループを展開または折りたたむことしかできませんでした。

強化リストについて詳しくは、[強化リストの使用](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)を参照してください。

### 時間分割レポートでの選択の表示

>[!NOTE]
>
>プロダクションリリース日：2026年10月27日（PT）

時間分割レポートで新しいビューを作成する際のエクスペリエンスが合理化され、1つのビュータイプしか使用できない場合に、ビュータイプを選択する必要がなくなりました。

### 時系列レポートの合計列をピン留めする

>[!NOTE]
>
>プロダクションリリース日：2026年10月27日（PT）

**合計**&#x200B;列をピン留めできるようになりました。これにより、時間経過したレポートの右側に表示されたままになります。

この機能は、人員配置プランなど、マトリックスビューを使用する他の画面でも利用できます。
