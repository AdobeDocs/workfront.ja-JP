# 2026年第4四半期のAdobe Workfrontの制限付き機能のリリースアクティビティ

この記事では、2026年第3四半期中にリリースされるWorkfront機能の限定提供について説明します。

<!--keep the sentence below for all future quarterly release pages-->

Adobe Workfront向けにリリースされたすべての制限付き機能の一覧については、[Adobe Workfront制限付き機能リリースアクティビティ：記事インデックス &#x200B;](/help/quicksilver/product-announcements/product-releases/limited-availability-release-activity/limited-availability-release-activity-article-index.md)を参照してください。

## 制限付き機能のリリースノート

この節には、新機能のリリースノートが含まれています。

### 拡張リストへの時間段階レポートの移行

>[!NOTE]
>
>プロダクションのリリース日：未定

時間段階レポートは、強化されたリスト形式に移行され、強化されたビュー管理が提供されます。 拡張リストでは、データのフィルタリングとグループ化、列の表示と非表示の設定をすばやく行うことができます。 これらの環境設定は、他のユーザーと保存して共有できる「ビュー」として組み合わされます。 一般的なテンプレートからレポートを作成し、ビューを使用してレポート構造を整理し、データの範囲を狭めることができます。

移行前にユーザーが既存のレポートに対して既に設定していた設定（フィルター、グループ化、列の表示）は保存され、**マイビュー** カテゴリのビューに変換されます。 レポートへのアクセス権を持つユーザーは、そのビューを自動的に共有できます。

デフォルトのビューも各レポートタイプに対して作成されます。 例えば、タスクレポートでは、デフォルトの名前は「時間段階的タスクのデフォルトビュー」です。 システム管理者は、レイアウトテンプレートの各レポートタイプのデフォルトのビューを設定できます。

>[!NOTE]
>
>システム内の既存のデータは変更されません。 レポート内のデータのビューのみが変更されました。

ビューと拡張リストについて詳しくは、[拡張リストの使用](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)を参照してください。
