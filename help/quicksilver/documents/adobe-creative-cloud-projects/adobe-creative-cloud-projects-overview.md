# Adobe Creative Cloud プロジェクトの概要

Workfront プロジェクトには、Adobe Photoshop、Illustrator、InDesignから直接アクセスできます。 Creative Cloud アプリのウィンドウの左側にあるプロジェクトパネルでは、アプリを離れることなく、Workfront プロジェクトでドキュメントを開いたり、編集したり、保存したりできます。 新しいファイルをWorkfront プロジェクトに直接保存することもできます。

Adobe クラウドストレージを使用するプロジェクトのみが、他のCreative Cloud プロジェクトと共にプロジェクトパネルに表示されます。 このパネルは、Workfrontのドキュメントのフォルダー構造を反映しています。

承認ワークフローがある文書を保存すると、Workfrontは新しいバージョンを作成し、承認履歴を保持します。 承認ワークフローがないドキュメントを保存すると、Workfrontは最新バージョンを更新します。

## 前提条件

* 組織は、Adobe クラウドストレージをサポートするWorkfrontのバージョンを使用している必要があります。
* WorkfrontとPhotoshop、Illustrator、またはInDesignは、同じAdobe Identity Management System （IMS）組織で使用権限を持っている必要があります。


## Photoshop、IllustratorまたはInDesignのプロジェクトパネルで実行できること

* Workfront プロジェクトフォルダーとドキュメントを、Photoshop、Illustrator、またはInDesignで直接開きます。 アクセス権のあるWorkfront プロジェクトは、プロジェクトパネルに表示されます。
* ファイルを編集し、変更内容をWorkfront プロジェクトに保存します。

詳しくは、[Creative Cloud アプリケーションでのWorkfront ドキュメントの使用](/help/quicksilver/documents/adobe-creative-cloud-projects/use-wf-documents-in-cc-apps.md)を参照してください。

>[!NOTE]
>
>従来のWorkfront ストレージプロジェクトは、プロジェクトパネルではサポートされていません。

## 関連統合

Adobe Cloud Driveを使用してWorkfront ファイルを管理し、変更内容をWorkfrontのドキュメントに自動的に保存することもできます。 詳しくは、[Adobe Cloud Driveの概要](/help/quicksilver/documents/adobe-cloud-drive/adobe-cloud-drive-overview.md)を参照してください。
