# Adobe Cloud Driveの使用

Adobe Cloud Driveをインストールした後、Finderまたはファイルエクスプローラーから直接Adobe クラウドストレージプロジェクトを操作できます。 任意のアプリケーションでファイルを開いて編集し、オフラインで作業し、Adobe Cloud Driveで変更内容をクラウドに同期できます。

Adobe Cloud Driveのインストールについて詳しくは、[Adobe Cloud Driveのインストール &#x200B;](/help/quicksilver/documents/adobe-cloud-drive/install-adobe-cloud-drive.md)を参照してください。

## プロジェクトへのアクセス

1. Finder （Mac）またはFile Explorer （Windows）を開きます。
1. **Adobe Cloud Drive**&#x200B;に移動します。
1. Workfrontでアクセスできるプロジェクトの一覧を参照します。 任意のプロジェクトフォルダーを開いて、そのファイルとサブフォルダーを表示します。

   >[!NOTE]
   >
   >* プロジェクトフォルダーは、トップレベルでは読み取り専用です。 プロジェクトフォルダー自体の名前を変更、削除、移動することはできません。
   >* プロジェクトフォルダー内のファイルやフォルダー（開く、編集、作成、削除など）を操作できます。
   >* 従来のWorkfront プロジェクトは、Adobe Cloud Driveには表示されません。 Adobe クラウドストレージに保存されているプロジェクトのみが使用できます。

### エラーのツールヒント

同期エラーまたは問題が発生した場合は、ファイルまたはフォルダーアイコンにカーソルを合わせると、問題を説明するツールヒントが表示されます。

| エラーカテゴリ | ツールヒント | 意味 |
|---|---|---|
| 同期を除外 | サポートされていないファイルタイプ | このファイル形式は、Adobe Cloud Driveではサポートされていません。 |
| 同期を除外 | サポートされていないファイル名 | ファイル名はAdobe Cloud Driveではサポートされていません。 |
| 同期を除外 | 親プロジェクトが削除されました | 親Workfront プロジェクトが削除されました。 |
| 同期が中断されました | ファイル内容がサポートされていません | ファイルの内容を同期できません（セキュリティの問題が検出されたなど）。 |
| 同期が中断されました | ファイル名に不正な文字が含まれています | ファイル名に無効な文字が含まれています。 |
| 同期が中断されました | フルパスが長すぎます | ファイルのパスが許可されている最大長を超えています。 |
| 同期が中断されました | 書き込み権限がありません | このファイルまたはプロジェクトへの書き込みアクセス権が取り消されました。 |
| 同期エラー | 認証の問題 | ログイン資格情報に問題があります。 |
| 同期エラー | クラウドストレージが利用できません | Adobe クラウドサービスは一時的に利用できません。 |
| 同期エラー | クラウドストレージがいっぱいです | クラウドストレージの割り当て量がいっぱいです。 |
| 同期エラー | ローカルディスクがいっぱいです | ローカルディスクに十分な空き容量がありません。 |
| 同期エラー | インターネット接続なし | お使いの端末がインターネットに接続されていません。 |
| 同期エラー | 予期しないエラー | 同期中に予期しないエラーが発生しました。 |
| 同期エラー | ブロックされたアカウント | あなたのアカウントはサービスによってブロックされています。 |

>[!NOTE]
>
>システム レベルのエラー（切断、認証エラー、ネットワークが利用できない、ローカル ディスクがいっぱいになっている、クラウド ストレージがいっぱいになっている場合など）は、個々のファイルではなく、システム トレイ（Windows）またはメニューバー（Mac）に表示されます。

### 同期の除外リスト

Adobe Cloud Driveは、特定のシステム生成、一時、およびロックファイルを同期から除外します。 次のファイルタイプとパターンは除外されます。

| カテゴリ | ファイルの種類/パターン | 説明 |
|---|---|---|
| システムファイル | `.DS_Store`, `Thumbs.db` | オペレーティングシステムのメタデータとサムネールキャッシュファイル。 |
| システムおよび仮想メモリファイル | `*.sys` （例：`hiberfil.sys`、`pagefile.sys`、`swapfile.sys`） | 仮想メモリ、休止状態、またはその他のオペレーティングシステム機能に使用される大きなシステムファイル。 |
| macOSのインデックスファイル | `.Spotlight-V100`, `.fseventsd` | macOS Spotlightのインデックス作成とファイルシステムイベントトラッキングファイル。 |
| 一時ファイルとバックアップファイル | `*.tmp`, `*.swp`, `*~`, `*.bak` | アプリケーションによって生成された一時ファイル、一時ファイル、またはバックアップファイル。 |

## ファイルをオープン

1. Adobe Cloud Driveで、ファイルに移動します。
1. ファイルをダブルクリックします。

   ファイルがデフォルトのアプリケーションで開きます。

Adobe Cloud Driveは、コンピューターにインストールされているアプリケーションで開くことができるあらゆる種類のファイルをサポートしています。

* Adobe Creative Cloud形式（PSD、AI、INDD、PRPROJ、AEPなど）
* Microsoft Office ドキュメント（DOCX、XLSX、PPTX）
* 画像（JPG、PNG、GIFなど）
* ビデオファイル（MP4、MOVなど）

>[!NOTE]
>
>クラウドドキュメント形式（PSDC、AIDCなど）は、Adobe Cloud Driveからアクセスすると、標準の同等の形式（PSD、AIなど）として開きます。

## ファイルの編集と保存

1. Adobe Cloud Driveからファイルを開きます。
1. アプリケーションで変更を加えます。
1. **ファイル**/**保存**&#x200B;を選択するか、Ctrl+S （Windows）またはCmd+S （Mac）を押してファイルを保存します。

   変更内容はAdobe クラウドストレージに自動的に同期されます。

>[!IMPORTANT]
>
>**ファイル**/**保存**&#x200B;またはキーボードショートカットを使用してファイルを保存します。 **別名で保存**&#x200B;を使用してコピーを作成しないでください。これは、ドライブ内に重複ファイルが生成されるためです。

## 新しいファイルを作成または追加

プロジェクト内で新しいファイルを直接作成することも、ローカルストレージから既存のファイルを追加することもできます。

### アプリケーションから新しいファイルを作成する

1. ファイルの作成に使用するアプリケーションを開きます。
1. 通常どおりにファイルを作成します。
1. 保存時に、Adobe Cloud Drive プロジェクトフォルダー内の場所を選択します。

   ファイルがAdobe Cloud Driveに表示され、Adobe クラウドストレージに同期されます。

### 既存のファイルをプロジェクトに追加

1. Finder （Mac）またはファイルエクスプローラー（Windows）で、Adobe Cloud Driveでプロジェクトフォルダーを開きます。
1. ローカルストレージからプロジェクトフォルダーにファイルをドラッグまたはコピーします。

   ファイルはAdobe クラウドストレージに自動的に同期されます。

## ファイルとフォルダーをオフラインで使用できるようにします

ファイルまたはフォルダーがオフラインで利用可能な場合は、インターネットに接続しなくても開いて編集できます。 オフラインファイルは、ローカルディスク領域を使用します。

### デバイス上にファイルまたはフォルダーを保持する

1. Adobe Cloud Driveのファイルまたはフォルダーを右クリックします。
1. 「**常にこのデバイスを使用する**」を選択します。

   ファイルまたはフォルダーはローカルキャッシュにダウンロードされ、オフラインでも使用できます。

### オフラインアクセスを削除して空き容量を増やす

1. オフラインファイルまたはフォルダーを右クリックします。
1. 「**空き領域**」を選択します。

   ファイルまたはフォルダーはクラウドストレージ内に残りますが、ローカルキャッシュから削除されます。

>[!NOTE]
>
>オフラインファイルとフォルダーは、ローカルディスク領域を使用します。 空き容量を増やす必要がなくなったファイルとフォルダーのオフラインアクセスを削除します。

## ファイルをローカルストレージにコピー

Adobe Cloud Driveからローカルドライブにファイルをコピーできます。 元のファイルはAdobe Cloud Driveに残り、コピーは独立したローカルファイルになります。

1. Adobe Cloud Driveでファイルを右クリックします。
1. 「**コピー**」を選択し、目的のローカルドライブ上の場所にファイルを貼り付けます。

   ファイルが宛先にコピーされます。 元のファイルはAdobe Cloud Driveに残ります。

>[!NOTE]
>
>ローカルストレージにコピーされるファイルは、独立したコピーです。 ローカルコピーに加えた変更は、Adobe クラウドストレージに同期されません。

## クラウドへのファイルのアップロード（直接アップロード） {#direct-upload}

ダイレクトアップロードは、最初にAdobe Cloud Drive フォルダーにコピーすることなく、コンピューターからAdobe クラウドストレージにファイルを直接送信します。

### ファイルのアップロード

1. Finder （Mac）またはFile Explorer （Windows）でファイルを右クリックします。
1. 「**クラウドにアップロード**」を選択します。
1. 宛先ピッカーで、Adobe Cloud Driveのいずれかのプロジェクト内の場所を選択し、**ここからアップロード**&#x200B;をクリックします。
1. 同期アクティビティウィンドウの&#x200B;**直接アップロード** セクションで進行状況を監視します。

### ダイレクトアップロードについて知っておくべきこと

* 直接アップロードは、アイテムをクラウドにコピーします。 元の項目は現在の場所に残ります。
* 一度に複数の項目を選択してアップロードできます。
* 「ダイレクトアップロード」セクションには、最大500個までの個々のファイルのみが一覧表示されます。
* ユーザーホームディレクトリまたは接続されている任意の外部ドライブからアイテムをアップロードできます。 iCloud Driveや`~/Library/CloudStorage`などの他のクラウドストレージロケーションはサポートされていません。
* 資格のあるAdobe アカウントでログインする必要があります。 アップロードを開始するためにインターネット接続は必要ありません。 接続がなければ、アップロードはキューに入れたままになります。
* 同期を一時停止すると、進行中のアップロードがキャンセルされます。 同期を再開すると、キュー内のアップロードは自動的に再開されます。
* アップロード中にAdobe Cloud Driveを終了すると、進行中のアップロードはキャンセル済みとしてマークされます。 キューに入ったアップロードは、アプリの再起動時に自動的に再開されます。
* 非表示ファイル、シンボリックリンク、エイリアスはサポートされていません。
* Adobe Cloud Driveは、同時に実行されるアップロード数を制御します。 残りのアップロードは、スロットが使用可能になるまでキューに入れたままになります。
* 「3つのファイルのアップロード」など、アップロードの失敗を含むアップロードのライブカウントが表示されます。 すべてのアップロードが正常に完了すると、カウントは「3つのファイルがアップロードされました」などの概要に変わります。 「**却下**」を選択して削除します。

### アップロードリストの管理

各アクションは、該当する場合にのみ使用できます。

* **すべてのアップロードをキャンセル：** アップロードがキューに入っているか進行中の場合に使用できます。 それらをすべてキャンセルします。
* **失敗したアップロードの再試行：**&#x200B;再試行可能な失敗したアップロードが存在する場合に使用できます。 それらをすべて再試行します。 再試行できないアップロードは変更されません。
* **クリア：** アップロードがキューに入っていない場合や進行中の場合に使用できます。 完了、失敗、キャンセルされたすべての項目を削除します。 アップロード済みのローカルファイルやコンテンツは影響を受けません。
* **自動消去：**&#x200B;完了、失敗、およびキャンセルされた項目は、最後の更新から24時間後に自動的に削除されます。 キューに入っているアイテムや処理中のアイテムは、自動的に削除されません。

## 同期を一時停止して再開 {#pause-resume-sync}

Adobe Cloud Driveは、低速またはメーター制限付きのインターネット接続などでファイルのアップロードやダウンロードを行いたくない場合は、一時停止できます。 同期が一時停止されている間、変更はクラウドに送信されず、クラウドからの変更はコンピューターにダウンロードされません。 同期は、再開するまで一時停止されたままです。

### 同期を一時停止

1. システムトレイ（Windows）またはメニューバー（Mac）のAdobe Cloud Drive アイコンをクリックします。
1. Adobe Cloud Drive ウィンドウの右上隅にある&#x200B;**Menu** アイコン （≡）をクリックします。
1. **同期を一時停止**&#x200B;を選択します。

   >[!TIP]
   >
   >Adobe Cloud Drive ウィンドウを開いた状態で、Ctrl + P キー（Windows）またはCommand + P キー（Mac）を押すこともできます。

   Adobe Cloud Drive ウィンドウに&#x200B;**Sync is paused**&#x200B;と表示され、「**ファイルは再開するまで同期されません**」というメッセージが表示されます。 Adobe Cloud Drive アイコンにカーソルを合わせると、**Adobe Cloud Drive （一時停止）**&#x200B;と表示されます。

>[!NOTE]
>
>一時停止の同期は、ログインしていてAdobe Cloud Driveが接続されている場合にのみ使用できます。

### 同期を再開

1. システムトレイ（Windows）またはメニューバー（Mac）のAdobe Cloud Drive アイコンをクリックします。
1. 次のいずれかの操作を行います。

   * **再開**&#x200B;をクリックします。
   * **メニュー** アイコン （≡）をクリックし、**同期を再開**&#x200B;を選択します。 ウィンドウを開いた状態で、Ctrl + R キー（Windows）またはCommand + R キー（Mac）を押すこともできます。

   Adobe Cloud Driveは、同期が一時停止されている間に行った変更を含め、再度同期を開始します。

## バージョン履歴の表示と管理 {#version-history}

Adobe Cloud Driveのバージョン履歴を使用して、サポートされているファイルの保存されたクラウドバージョンを参照し、バージョンの詳細とサムネールを表示して、以前のバージョンに戻すことができます。 必要な権限がある場合は、バージョンの名前と説明を編集することもできます。

### バージョン履歴を表示

1. FinderまたはファイルエクスプローラーでAdobe Cloud Drive フォルダーに移動します。
1. サポートされているファイルを選択します。
1. ファイルを右クリックし、**バージョン履歴**&#x200B;を選択します。
1. バージョンを選択して、使用可能な詳細とサムネールを表示します。

   ファイルに以前のバージョンがない場合、**以前のバージョン**&#x200B;は表示されません。 サムネールは、ファイルやバージョンごとに使用できない場合があります。

### バージョン情報を編集

1. ファイルのバージョン履歴を開きます。
1. 更新するバージョンを選択します。
1. バージョンのオプションメニューを開き、**バージョン情報を編集**&#x200B;を選択します。
1. **バージョン名**&#x200B;または&#x200B;**説明**&#x200B;を入力してください。
1. 「**保存**」を選択します。

   更新された情報は保存され、バージョン履歴を再度開くと表示されます。

### 以前のバージョンに戻す

1. ファイルのバージョン履歴を開きます。
1. 復元するバージョンを選択します。
1. 「**このバージョンに戻す**」を選択します（使用可能な場合）。
1. 同期が完了するのを待ちます。
1. ファイルを再度開いて、選択したバージョンのコンテンツが現在のバージョンであることを確認します。

## 同期アクティビティを表示 {#sync-activity}

Sync Activityは、コンピューター上のAdobe Cloud Drive フォルダーとAdobe クラウドストレージ間の最近のアクティビティを表示します。 アップロードとダウンロードのモニタリングや、完了した変更の確認、同期できない項目の特定に使用できます。

### 同期アクティビティを表示

1. メニューバー（Mac）またはシステムトレイ（Windows）で「Adobe Cloud Drive」アイコンを選択します。
1. ステータスの概要の横にある矢印を使用して、「同期」アクティビティセクションを展開します。
1. リストされた項目とそのステータス指標を確認します。 ステータスインジケーターにカーソルを合わせると、転送の進行状況、完了した操作、エラーメッセージが表示されます。
1. 項目の横にある詳細アクションメニューを選択して、その項目で使用可能なアクションを表示します。

### 同期アクティビティについて知っておくべきこと

* 通常の同期では、アップロード、ダウンロード、作成、名前の変更、移動、削除など、Adobe Cloud Drive フォルダーを介して行われた変更を追跡します。
* 通常の同期リストには、最大500個の最近のエントリが含まれます。 新規または更新されたエントリが上部に表示されます。 リストが制限に達すると、古いエントリが削除される場合があります。
* エントリは、名前またはメタデータの解決中に、最初に&#x200B;**準備中…**&#x200B;と表示できます。
* 概要には、現在同期している項目の数が表示されます。 **同期完了**&#x200B;とは、現在アクティブなアイテムがないことを意味します。 失敗した項目または除外された項目のリストを検査します。この概要を、すべての項目が成功したことを確認するものとして扱うのではなく、確認してください。
* 同期から除外されたファイルとフォルダーには、サポートされていない名前、サポートされていないタイプ、またはその他の除外の理由を説明するエラーが表示される場合があります。
* ログアウトすると、アクティビティは消去されます。 リストはアクティビティビューであり、永続的な監査履歴ではありません。

## Workfrontで項目を開く {#open-in-workfront}

Workfrontで開くと、Adobe Cloud Driveのアイテムから、ブラウザーのWorkfrontの対応する場所に移動します。 このツールを使用すると、Workfrontのクラウドアイテムを手動で検索せずに引き続き操作できます。

### Finderまたはファイルエクスプローラーからアイテムを開く

1. Finder （Mac）またはファイルエクスプローラー（Windows）でAdobe Cloud Drive フォルダーを開きます。
1. Workfront アイテムに関連付けられている1つのファイルまたはフォルダーを選択します。
1. 項目を右クリックし、**Workfrontで開く**&#x200B;を選択します。

   対応するWorkfrontの場所がブラウザーで開きます。 プロンプトが表示されたら、その項目へのアクセス権を持つアカウントでログインします。

### 同期アクティビティから項目を開く

1. メニューバー（Mac）またはシステムトレイ（Windows）で「Adobe Cloud Drive」アイコンを選択します。
1. 同期アクティビティセクションを展開します。
1. 対象となる完了済みの削除されていない項目の場合は、その他の操作メニューを開き、**Workfrontで開く**&#x200B;を選択します。
1. 直接アップロードを通じてアップロードされたファイルの場合は、**直接アップロード** セクションの完了したエントリに同じアクションを使用します。

### Workfrontのオープンについて知っておくべきこと

* 一度に1つの項目のみを選択します。 Workfrontで選択した複数の項目を開くことはできません。
* ファイルエクスプローラーでは、Adobe Cloud Drive フォルダー以外の項目とドライブルート自体に対してコマンドが非表示になります。 複数の項目が選択されている場合は無効になります。
* アイテムには、対応するWorkfrontの場所が必要です。 一部のフォルダーやその他のアイテムは、Adobe Cloud Driveに表示されていても、Workfront マッピングが含まれていない場合があります。
* アップロードが完了していない新しいローカルアイテムには、まだWorkfront リンクがない可能性があります。 アップロードが完了するのを待ってから、もう一度やり直してください。
* 通常の同期アクティビティでは、アクションは対象となる完了したエントリに対してのみ提供されます。 アクティブなエントリ、失敗したエントリ、または削除されたエントリに対しては提供されません。
* 「直接アップロード」では、アクションは完了したアップロード用に提供されますが、キューに入れたエントリ、アップロードに失敗したエントリ、キャンセルされたエントリ用には提供されません。
* Adobe Cloud Driveにログインする必要があります。 Workfrontでは、ブラウザーで個別にログインするように求められることもあり、Workfrontの権限は引き続き適用されます。
* キャッシュされていないリンクを取得し、Workfrontにアクセスするには、インターネット接続が必要です。 以前に解決したリンクでは、Workfrontへのオフラインアクセスを提供できません。
* この操作を実行すると、ブラウザーでWorkfrontが開きます。 デスクトップアプリケーションでファイルを開いたり、別のコピーをアップロードしたり、ローカルのオフライン可用性を変更したりすることはありません。

### Workfrontで開く

| 項目または状態 | Workfront ビヘイビアーで開く | 必要なアクション |
| --- | --- | --- |
| Adobe Cloud Driveの対象となる1つのアイテム | 対応するWorkfrontの場所を開きます。 | 「**Workfrontで開く**」を選択します。 |
| 複数の選択項目 | 複数の項目を開くことはできません。 ファイルエクスプローラーはコマンドを無効にします。 | 1つの項目を選択します。 |
| 新しい項目がアップロード中 | Workfrontのリンクがまだ利用できない場合があります。 | アップロードが完了するまで待ってから、もう一度やり直してください。 |
| 標準の同期エントリが完了しました | アイテムが適格で、削除されていない場合に使用できます。 | エントリのその他のアクション メニューを使用します。 |
| 完了した直接アップロード エントリ | アップロード完了後に使用できます。 | エントリのその他のアクション メニューを使用します。 |
| Workfront マッピングのない項目 | Workfrontで利用できないことを示すメッセージが表示されます。 | Workfrontで直接項目を確認するか、サポートされている別の項目を選択します。 |
| 標準の同期エントリを削除しました | アクションは使用できません。 | 削除した項目を調査する必要がある場合は、Workfrontを直接使用します。 |

## Adobe Cloud Driveからログアウトする

Adobe Cloud Driveからログアウトすると、Finderまたはファイルエクスプローラーにドライブが表示されたままになります。 ただし、ログアウト中にドライブ内で行った変更や、ログアウト前に同期されなかった変更は、クラウドに同期されません。

次に何が起こるかは、どのアカウントでログインし直すかによって異なります。

### 同じアカウントで再度ログインする

Adobe Cloud Driveは、ログアウト時にローカルにマウントされたフォルダーを保持します。 同じ資格情報で再度ログインする場合：

* Adobe Cloud Driveは、既存のマウントを自動的に再利用します。
* ログアウト前に行った同期されていない変更はすべて保持され、接続が復元されると同期されます。
* あなたからの行動は必要ありません。

### 別のアカウントでログイン

ログアウト後に別のAdobe アカウントでログインする場合：

* 現在マウントされているフォルダーは、自動的に名前が変更され、バックアップされます。 バックアップ フォルダー名は、次の形式を使用します：`Adobe Cloud Drive <usermail>_<short_guid> (backup yyyy-MM-dd HH-mm-ss)`。
* 新しいアカウントにマッピングされたAdobe Cloud Driveは、通常どおりFinderまたはファイルエクスプローラーで利用できるようになります。
* 同期されていない作業は、削除する前にバックアップフォルダーから手動で復元できます。

>[!NOTE]
>
>バックアップフォルダーは、Macの`~/Library/CloudStorage`とWindowsの`C:\Users\<user>\`に保存されます。 アカウントを複数回切り替えると、複数のタイムスタンプ付きバックアップフォルダーが作成されます。 バックアップを定期的に確認してクリーンアップし、ディスク容量を解放します。

## ファイルの競合を解決

競合は、次のいずれかの状況で発生する可能性があります。

* 複数のユーザーが同じファイルを同時に編集または削除します。
* ファイルは、別のユーザーが開いている間に変更されます。
* ネットワークの中断が同期の問題を引き起こす。

### Adobe Cloud Driveによる競合の解決方法

Adobe Cloud Driveでは、競合に対して次の重複方法が使用されます。

* **ファイルがロックされていません。** 複数のユーザーが同時にファイルを編集できます。
* **自動複製。** Adobe Cloud Driveが競合を検出すると、両方のバージョンが保持されます。
* **名前をクリアします。** 競合ファイルには、ユーザー名とタイムスタンプが次の形式で含まれます：`filename (Conflicted copy from username on date_time).extension`。 例：`hero-banner (Conflicted copy from John on 2026-02-10_16-06-44).psd`

### 競合を手動で解決する

1. 競合ファイルを特定します。 競合ファイルのファイル名に「競合したコピー」があります。
1. 両方のバージョンを確認し、どれが正しいかを判断します。
1. 正しいバージョンを保持し、他のバージョンを削除します。
1. 保持しているファイルに適切な名前を付けます。

>[!TIP]
>
>競合を最小限に抑えるには：
>
>* ファイルを編集する前に、同期ステータスを確認します。
>* 誰がどのファイルを編集しているのかをチームメンバーに伝える。
>* 頻繁に保存して、変更をすぐに同期します。
>* 編集が終了したらファイルを閉じます。
