# CX担当者のスキル

{{preview-fast-release-general}}

>[!IMPORTANT]
>
>CX Coworkerは現在、ヘルスケアや金融など、機密データを扱う業界の企業には利用できません。 AI アシスタントは、これらの組織で利用できます。 詳しくは、[AI アシスタントの概要](/help/quicksilver/workfront-basics/ai-assistant/ai-assistant-overview.md)を参照してください。

この記事では、WorkfrontのCX Coworkerで現在利用可能なスキルを紹介します。

これらのスキルでカバーされている能力は、対話型インターフェイスを通じてCX Coworkerで利用でき、これらのスキルを直接呼び出す必要はありません。 ただし、スキルを直接呼び出す場合は、共同作業者パネルでスラッシュ `/`を入力し、スキルの名前を入力します。

プロンプトの例については、[Adobe Workfront MCP サーバーの使用](/help/quicksilver/workfront-basics/workfront-mcp-server/use-workfront-mcp-server.md)の記事のプロンプトを参照してください。

## Workfront計画に必要なスキル

### Workfront Planning Solution Architect

名前：`wf-planning-solution-architect`

このスキルは、次のようなWorkfront計画に関連する質問に答えることができます。

* Workspace デザイン
* 数式フィールドの構文
* API フィルタリング
* レコードの接続
* 自動化オプション
* レポート
* アクセスと権限
* 統合
* 価格帯による製品の制限

### Workfront計画の管理

名前：`manage-workfront-planning`

このスキルは、次のようなWorkfront計画オブジェクトをクエリおよび管理します。

* ワークスペース
* セクション
* レコードタイプ
* フィールド
* ビュー
* レコード

### Workfront オブジェクトの管理

名前：`manage-workfront-objects`

このスキルは、Workfrontのプロジェクト、タスク、イシュー、ポートフォリオ、プログラムを作成し、更新します。 例えば、次のようなものがあります。

* プロジェクトの作成
* タスクの追加
* 予定日の設定
* タスクの割り当て

### Workfront Dataのクエリ

名前：`query-workfront-data`

このスキルは、次のようなWorkfront オブジェクトに関する検索、リスト、レポートを行います。

* プロジェクト
* タスク
* イシュー
* ユーザー
* ポートフォリオ
* その他
