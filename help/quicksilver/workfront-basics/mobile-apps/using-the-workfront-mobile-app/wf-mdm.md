# [!DNL Adobe Workfront] for [!DNL Mobile Device Management]（MDM）

{{mobile-maintenance-mode}}

Adobe [!DNL Workfront]は[!DNL Mobile Device Management] （MDM）のプラットフォームと提携して、より安全で管理されたモバイル体験を企業に提供しています。 [!DNL Workfront] モバイルアプリは、次のモバイルデバイス管理プラットフォームで使用できます。

## Intune

Workfront モバイルアプリが[!DNL Microsoft Intune] アプリストアで利用できるようになりました。 Workfront管理者は、Intuneを通じてアプリをデバイスに割り当てることができます。

* iOS
* Android

Workfront インスタンスは、Adobe Identity Management システム（IMS）上にある必要があります。
