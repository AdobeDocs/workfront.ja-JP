# Adobe Workfront計画リリースアクティビティのアイデア創出スペース

<span class="preview">このページの情報は、まだ一般に提供されていない機能を指します。 これは、**アイデア創出スペース Beta** プログラムの一部としてのみ使用できます。</span>

<span class="preview">詳細については、[Adobe Workfront Planningのアイデア創出スペースの基本を学ぶ](/help/quicksilver/planning/ideation/get-started-with-planning-ideation.md)を参照してください。</span>

この記事では、**アイデア創出スペース Beta**&#x200B;期間中にWorkfront計画のアイデア創出スペース用にリリースされる機能について説明します。 「Open Beta for Ideation」は、2026年11月12日から2027年2月1日の間に開催予定です。

Adobe Workfront Planning リリースについては、[Adobe Workfront Planning リリースアクティビティ：記事インデックス ](/help/quicksilver/product-announcements/product-releases/planning-release-activity/planning-release-activity-article-index.md)を参照してください。

## Adobe Workfront計画のアイデア創出スペースの新しいホームエリア

>[!NOTE]
>
>アイデア立案スペースベータ版のお客様のプレビューおよび実稼動環境で利用可能：2026年11月25日

Workfrontのワッフルメニューからアイデア創出スペースにアクセスすると、アイデア創出スペースのホームエリアが開きます。 ここから、既存のカンバスを再度開いたり、作成したりできるので、既存のカンバスに移動するために空白のカンバスから始める必要はありません。 ホーム領域には、最近のキャンバスがタイルとして表示され、画面の下部に他のすべてのキャンバスが一覧表示され、検索ボックスが含まれます。 キャンバス内で作業している場合は、新しいホームボタンを使用して、アイデア創出スペースのホームエリアに戻ります。

詳しくは、「[ アイデア創出スペースで概要を作成する](/help/quicksilver/planning/ideation/create-briefs-in-ideation-space.md)」を参照してください。
