# アーキテクチャ：記事インデックス

{{planning-important-intro}}

マーケティング業務のリーダーとして、Adobe Workfront プランニングを使用すると、すべてのチームのマーケティングライフサイクル全体の作業を整理できます。

Workfront プランニングを使用すると、組織が使用するオブジェクトタイプ（またはレコードタイプ）を決定することから、それらのオブジェクトを相互にリンクする方法を設定することまで、ワークフローを完全にカスタマイズできます。

また、Workfront プランニングは他のシステムのオブジェクトタイプにリンクすることもでき、すべてのプロセスに対して一貫性のあるフレームワークを作成できます。
